# 01 — Présentation du projet

## Contexte

Projet réalisé dans le cadre de la sélection **CDA — Concepteur Développeur d'Applications** à **Simplon Clermont-Ferrand**, entretien prévu le **24 juin 2026**.

La carte de visite sert de support d'échange lors de l'entretien technique : le jury peut lire le code source, naviguer sur la version déployée et questionner les choix techniques.

---

## Brief Simplon

| Champ | Valeur |
|---|---|
| Compétence ciblée | Réaliser une page web simple |
| Tags | HTML5 / CSS3 |
| Durée | 2 jours |
| Livraison | USB ou URL en ligne |

**Brief client (verbatim) :**
> *"En tant que chef de projet je veux voir les informations concernant le.a candidat.e afin d'échanger sur les termes techniques."*

---

## Objectif personnel

Dépasser le brief minimal (une page statique) en livrant une réalisation qui démontre :

- La maîtrise de HTML5 sémantique et CSS3 avancé (flip 3D, variables, grid/flexbox)
- Un design soigné et cohérent (palette, typographie, dark mode)
- Une attention portée à l'accessibilité (ARIA) et à la performance (Lighthouse 100/95)
- Une organisation de code professionnelle (découpage CSS en 3 fichiers, JS propre)
