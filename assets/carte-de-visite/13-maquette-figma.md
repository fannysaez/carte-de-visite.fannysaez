## Icônes Desk Deco — 11 juin 2026

22 frames "Desk Deco — passions" (Desktop + Tablette) remplies avec les vrais icônes FA6 via le Plugin API Iconify dans Figma.

| Paramètre | Valeur |
|---|---|
| Source | `api.iconify.design` (XHR) |
| Couleur | Teal `#1ebfc1` |
| Taille | 22px |
| Alignement | Centré dans les ellipses |

**Icônes utilisées :**

| Identifiant FA6 | Passion |
|---|---|
| `fa6-solid:person-swimming` | Natation |
| `fa6-solid:cube` | Impression 3D |
| `fa6-solid:palette` | Graphisme |
| `fa6-solid:scissors` | Scrapbooking |
| `fa6-solid:code` | Développement |

**Mobile :** badges masqués (`display: none`) — aucun changement sur les frames Mobile.
